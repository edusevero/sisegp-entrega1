Modelo — Arquétipo DITIC 4.1 Aplicação de exemplo para o padrão de desenvolvimento TJRS

Finalidade: Demonstrar os padrões, componentes e boas práticas do arquétipo DITIC para desenvolvimento de aplicações Angular no TJRS.

Recursos disponíveis:

  • Autenticação: Integração com Keycloak via OAuth2
  • Menu de Perfil: Acesse via avatar no header para gerenciar preferências
  • Acessibilidade: Controles de tamanho de fonte, fonte e espaçamento entre letras
  • Feature CRUD: Exemplo de implementação com validação e integração com backend
  • Componentes Reutilizáveis: Header, sidebar e footer da biblioteca @ditic/modelo-ui-lib
  • Padrões Angular: Standalone components, signals, reactive forms e lazy loading

A biblioteca @ditic/modelo-ui-lib fornece:

  • Layout: Header, sidebar, footer e componentes de navegação
  • Componentes: Tabelas responsivas, busca, status, timeline e notificações
  • Diálogos: Confirmação e informação
  • Serviços: Autenticação, carregamento, acessibilidade, fala e captura de imagem
  • Validadores: CPF, CNPJ e CNJ
  • ... e muitos outros recursos, acesse a wiki: https://gitlab.tjrs.jus.br/ditic/assesgov/arqsis/modelo4/modelo-ui/-/wikis/home
Observação: Esta página inicial é apenas um exemplo de boas-vindas da aplicação, e não deve ser uma rota autenticada. Caso seja autenticada, o usuário será redirecionado para a página de login após o logout, entrando em loop.
